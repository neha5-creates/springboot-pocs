# Employee Management System

## Overview

Employee Management System built using Spring Boot and PostgreSQL.

## Technology Stack

- Java 21
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Hibernate
- Swagger OpenAPI
- Maven

## Features

- Create Employee
- Get Employee By ID
- Get All Employees
- Update Employee
- Delete Employee
- Validation
- Exception Handling

## Run Application

```bash
mvn spring-boot:run
```

## Database

PostgreSQL
